# Web 工作台

> [English](./web-workbench.md) | 简体中文

Web 工作台是浏览器界面，读取的仍是 CLI 使用的 `~/.lattice` 数据。它直接读本地文件，不需要任何账号。

## 启动工作台

```bash
# 启动工作台（默认端口 14527）
ltc web
# 使用自定义端口
ltc web --port 8080
# 不自动打开浏览器
ltc web --no-open
```

工作台默认服务 `http://localhost:14527`。路由由 URL 驱动，浏览器的前进后退可用，任何视图都能直接分享链接。

## 四种视角

| 视角 | 回答的问题 |
|---|---|
| **全局** | 项目、任务、规范之间如何连接？ |
| **任务** | 这个任务的目标、PRD、设计与进度是什么？ |
| **项目** | 这个仓库知道什么、当前有哪些活动？ |
| **规范** | 这里适用哪条规则，哪些任务依赖它？ |

按 `1`–`4` 切换视角。点击节点会在不丢失画布位置的前提下打开详情面板。

## 画布与布局

画布是关系图，不是仪表盘。边表示当前关系，小地图让大图保持方向感。三种布局对应不同的阅读任务：

- **力导向** — 整张图的分簇概览。
- **顺序** — 分层排布，便于阅读依赖顺序。
- **径向** — 一个焦点节点与其邻域环绕展开。

## 搜索与筛选

| 快捷键 | 动作 |
|---|---|
| `⌘K` / `Ctrl+K` | 聚焦侧栏搜索 |
| `⌘P` / `Ctrl+P` | 打开全局搜索 |
| `⌘F` / `Ctrl+F` | 开/关画布搜索 |
| `Esc` | 关闭搜索或详情面板 |

侧栏可按节点类型、任务状态和规范层级筛选。关键词搜索在本地完成，语义检索不可用时仍然可用。

## 详情面板

- **任务** — PRD、设计、进度与 checkpoint 集中在一处。
- **规范** — 层级、frontmatter、正文以及引用它的任务。
- **项目** — Git 状态、注册路径与项目关系。

## 主题与布局

明暗主题可以跟随系统，也可以手动切换。窄屏下桌面侧栏变为抽屉，画布交互保持一致。

## 路由

| 路径 | 视图 |
|---|---|
| `/` | 全局关系图 |
| `/task/:taskId` | 任务视图 |
| `/project/:projectId` | 项目视图 |
| `/spec/:specId` | 规范视图 |

深链打开的面板与点击节点完全一致。
